# Architecture DAMM V2

Meteora DAMM V2 est un AMM à produit constant qui ajoute des fonctionnalités de tokens, de frais et de positions à une liquidité concentrée simplifiée. Le programme sépare les comptes de configuration, les pools, les positions et les SDK Rust. Les comptes de swap sont propres à chaque pool.
